# SG0HANN BOOST

Graphics and performance tweaker for CD Revive on Android (uses Shizuku, no root).

* Profiles (Normal, Low, Flat Look, Ultra, Extreme Potato)
* FOV changer, stretched resolution, detected visual settings (grass, sky, textures, effects)
* FPS limit, automatic backups, settings explorer
* English and German (follows the device language)

## Build

Push to `main` or run the workflow manually: the APK appears under *Actions → Artifacts*.
Push a tag such as `v3.0` to publish the APK as a GitHub Release.

The APK is signed with the fixed key in `app/debug.keystore`, so new builds install as updates.
